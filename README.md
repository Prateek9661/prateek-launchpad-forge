# Prateek Kumar Singh — Developer Portfolio

> BCA Student | Aspiring Software Engineer — building software foundations for tomorrow's technology.

A premium, dark-themed personal portfolio built with a "Futuristic Engineer Dashboard" design system: glassmorphism panels, electric-blue accents, terminal-inspired UI and motion-driven reveals.

**Live site:** https://prateek-launchpad-forge.lovable.app

---

## Highlights

- **Hero** — typing headline animation, portrait card and a live `engineer.ts` code panel
- **About & Skills** — narrative plus C, Java and tooling proficiency grouped by category
- **Certifications** — MongoDB, Google and NSDC learning credentials
- **Projects** — engineering case studies (Digital Logic Simulator, Student Record Management System, Java Utility Suite)
- **Learning Journey** — live progress tracking of current study areas
- **GitHub Activity** — terminal-style commit log and contribution heatmap
- **Contact & Footer** — direct channels with a terminal `whoami` sign-off
- **SEO ready** — meta tags, OpenGraph, Twitter cards and JSON-LD `Person` schema

## Tech Stack

| Layer | Technology |
| --- | --- |
| Framework | TanStack Start (React 19, SSR) |
| Language | TypeScript |
| Styling | Tailwind CSS v4 (OKLCH design tokens) |
| Animation | Motion (Framer Motion) |
| Icons | Lucide React |
| Build | Vite 7 |

## Getting Started

Requires Node.js 20+ and npm.

```sh
git clone https://github.com/Prateek9661/Protifilo-1.git
cd Protifilo-1
npm install
npm run dev
```

The dev server runs at `http://localhost:8080`.

```sh
npm run build    # production build
```

## Project Structure

```text
src/
├─ routes/

│  └─ index.tsx           # home page + SEO metadata

│  ├─ Hero.tsx            # typing animation + portrait
│  ├─ About.tsx           # narrative, skills, certifications
│  ├─ Projects.tsx        # case studies

│  ├─ Contact.tsx         # contact channels + footer
│  └─ primitives.tsx      # Section / Reveal building blocks
└─ styles.css             # design tokens & utilities
```
